# Task: Fix Calculator Bugs

The calculator in `src/calculator.js` has bugs. Fix all bugs so that all tests pass.

## Requirements

All four operations must work correctly:
- `add(a, b)` - returns sum of a and b
- `subtract(a, b)` - returns difference (a - b)
- `multiply(a, b)` - returns product of a and b
- `divide(a, b)` - returns quotient (a / b), throws error if b is zero

## Success Criteria

Run `npm test` and verify all tests pass (exit code 0).

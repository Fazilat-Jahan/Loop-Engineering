# Rehearse a Routine for Free

## Objective
Prove a prompt with one‑off runs before scheduling it.

## Methodology
1. Run a small routine (for example, summarizing recent commits) as a one‑off execution.
2. Force a failure deliberately—such as trying to read a file that does not exist—to capture the run transcript.

## Core Lesson
A "green" status only means the session ended without infrastructure errors; it **does not** guarantee that the task was logically successful.
